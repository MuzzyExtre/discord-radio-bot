# 📻 Радио-бот для Discord

Свой бот на слэш-командах: играет HLS-потоки (Soundpark Deep, Свое FM или любую
свою ссылку), умеет брать музыку из заданного текстового канала и сам
переподключается, если поток оборвался.

Всё ставится одной командой: `start.bat` создаёт окружение, ставит зависимости и
запускает бота. Проверить FFmpeg и потоки без запуска — `check.bat`.

**Зависимости закреплены:** `davey==0.1.7`. В версии 0.2.0 DAVE-сессия не получает
ключ шифрования (`can_encrypt=False`), бот «играет», но клиенты его не слышат.
Не обновляй эту версию вручную.

Для чтения ссылок из текстового канала нужно включить **Message Content Intent**
в Developer Portal (шаг 1, пункт 3). Без него работают слэш-команды и панель.

---

## Команды

| Команда | Что делает |
|---|---|
| `/radio` | Включить радио. `station` — станция из списка, `url` — своя ссылка на поток |
| `/play url` | Поставить трек по ссылке (прямая ссылка, YouTube, SoundCloud) |
| `/stop` | Остановить музыку и выйти из голосового канала |
| `/clear` | Очистить очередь — текущий трек играет дальше |
| `/panel` | Панель плеера с кнопками (появляется и сама после `/radio` и `/play`) |
| `/queue` | Показать очередь (до 20 треков) |
| `/search запрос` | Поиск в Яндекс.Музыке: выбираешь трек из списка — он в очереди |
| `/wave вид` | Волна Яндекс.Музыки: моя волна, жанр или настроение |
| `/skip` | Пропустить трек / перезапустить поток радио |
| `/status` | Что играет сейчас, сколько времени, громкость |
| `/volume уровень` | Громкость 0–150 % |
| `/yandextoken токен` | Токен Яндекс.Музыки — включает полные треки (вместо 30-секундных превью) |
| `/setchannel` | Выбрать текстовый канал, из которого бот берёт музыку |
| `/stations` | Список встроенных станций |

Встроенные станции: **Soundpark Deep** и **Свое FM**.

## Шаг 1. Создать бота в Discord (≈5 минут)

1. Открой <https://discord.com/developers/applications> → **New Application** →
   введи имя → **Create**.
2. Слева **Bot** → **Reset Token** → **Copy**. Токен показывается один раз;
   если потерял — просто сбрось заново.
3. На той же странице, блок **Privileged Gateway Intents** → включи
   **MESSAGE CONTENT INTENT** → **Save Changes**.
   Без этого бот всё равно запустится и будет играть радио по `/radio`, но
   ссылки из текстового канала читать не сможет.
4. Слева **OAuth2 → URL Generator**:
   - **Scopes**: `bot`, `applications.commands`
   - **Bot Permissions**: `View Channels`, `Send Messages`,
     `Read Message History`, `Add Reactions`, `Connect`, `Speak`
   - Скопируй ссылку внизу, открой её в браузере → выбери сервер → **Authorize**.

5. Команды появятся на сервере сразу после первого запуска.

> ID сервера (необязательно, но ускоряет появление команд): Discord →
> Настройки → **Advanced** → **Developer Mode** ON → правый клик по серверу →
> **Copy Server ID**.

## Шаг 2. Вписать токен

Скопируй `config.example.json` в `config.json` (или запусти бота один раз —
он создаст файл сам) и заполни:

```json
{
  "token": "СЮДА_ТОКЕН_БОТА",
  "guild_id": 0,
  "music_channel_id": 0,
  "auto_join": true,
  "volume": 60,
  "ffmpeg_path": "",
  "yandex_token": "",
  "max_tracks_per_link": 0,
  "panel_repost_after": 5
}
```

- `yandex_token` — токен Яндекс.Музыки. Без него треки из Яндекса играют
  30-секундными превью. Можно не трогать файл, а один раз выполнить
  `/yandextoken` в Discord (см. раздел «Яндекс.Музыка»).
- `max_tracks_per_link` — сколько треков брать с одной ссылки на плейлист/альбом.
  `0` — без ограничения (по умолчанию).
- `panel_repost_after` — через сколько новых сообщений в канале панель сама
  переезжает вниз (`5` по умолчанию, `0` — не переносить).

- `token` — токен из шага 1.
- `guild_id` — ID твоего сервера. С ним команды появляются мгновенно.
  `0` — синхронизация на всех серверах (команды могут появиться не сразу).
- `music_channel_id` — ID текстового канала для музыки (`0` — выключено).
  Проще задать командой `/setchannel` прямо в канале.
- `auto_join` — заходить в голосовой канал автора сообщения автоматически.
- `volume` — стартовая громкость в процентах.
- `ffmpeg_path` — пусто = искать `ffmpeg` в PATH (сейчас он там есть).

Токен можно не писать в файл, а положить в `.env` рядом с ботом:

```
DISCORD_TOKEN=твой_токен
```

## Шаг 3. Запуск

Двойной клик по **`start.bat`**.

Первый запуск сам создаст окружение и поставит зависимости, дальше — только
запуск. В консоли появится:

```
Бот вошёл как ИмяБота (id ...)
Ссылка для приглашения бота:
https://discord.com/oauth2/authorize?...
```

Остановить — `Ctrl+C` или закрыть окно.

Проверить потоки без запуска Discord: **`check.bat`**.

---

## Шаг 4. Проверка в Discord

1. Зайди в любой голосовой канал.
2. Напиши `/radio` → выбери **Soundpark Deep** → Enter.
3. Бот зайдёт в канал и заиграет. Проверь `/status`.
4. Остановить — `/stop`. Перезапустить поток — `/skip`.

Своя ссылка: `/radio url:https://твой-поток/stream.m3u8`.
Радио всегда считается «живым»: если поток оборвётся, бот сам перезапустит его
через 3 секунды.

---

## Шаг 5. Музыка из текстового канала

1. Зайди в нужный текстовый канал и напиши `/setchannel` (нужно право
   «Управление сервером»). Либо укажи канал: `/setchannel channel:#музыка`.
2. Кидай в этот канал ссылку — бот поставит её в очередь и отметит сообщение ✅.
3. Что понимает:
   - прямые ссылки: `.mp3`, `.m4a`, `.aac`, `.ogg`, `.opus`, `.flac`, `.wav`,
     `.m3u8` (HLS-радио);
   - вложения-аудио и видео;
   - **Яндекс.Музыка**: трек, альбом, исполнитель, плейлист (весь, без лимита);
   - YouTube / SoundCloud (через `yt-dlp`, уже установлен).
4. Если играло радио — трек из чата временно его заменит, а после трека радио
   включится снова.
5. Если бот не в канале, а автор сообщения сидит в голосовом — бот зайдёт сам
   (`auto_join: true`).

## Яндекс.Музыка

Кидаешь в `#music` (или в `/play`) ссылку вида:

- `https://music.yandex.ru/album/9553105/track/61304215` — один трек;
- `https://music.yandex.ru/track/132348101` — короткая ссылка на трек;
- `https://music.yandex.ru/album/9553105` — весь альбом;
- `https://music.yandex.ru/artist/792433` — популярные треки исполнителя;
- `https://music.yandex.ru/users/логин/playlists/3` — плейлист по логину;
- `https://music.yandex.ru/playlists/<uuid>` — плейлист по ссылке «Поделиться».

Бот берёт метаданные через неофициальное API `api.music.yandex.net`, а перед
каждым треком получает свежую подписанную ссылку на mp3 (она живёт около минуты,
поэтому ссылка запрашивается прямо перед запуском). Плейлист берётся целиком;
лимит можно задать в `config.json` — `max_tracks_per_link` (0 = без ограничения).

### Токен (для полных треков)

Без токена Яндекс отдаёт только **30-секундные превью**. Полные треки — с токеном
твоего аккаунта (для части треков нужна подписка Плюс).

Как получить:

1. Открой `music.yandex.ru` и войди в аккаунт.
2. F12 → вкладка **Network** → обнови страницу → выбери любой запрос к
   `api.music.yandex.net` → **Headers** → **Request Headers** → скопируй
   значение `Authorization: OAuth ...` (нужна часть после `OAuth `).
3. Вставь в Discord: `/yandextoken token:<токен>` — нужно право «Управление
   сервером». Перезапуск не нужен, токен сразу сохраняется в `config.json`.

Альтернатива: открой
`https://oauth.yandex.ru/authorize?response_type=token&client_id=23cabbbdc6cd418abb4b39c32c41195d`,
разреши доступ и скопируй `access_token` из адресной строки (от `access_token=`
до `&`).

Проверка: `/status` → поле «Яндекс.Музыка: токен есть».

### Волны

`/wave` или выбор в панели. «Моя волна» — персональная подборка аккаунта,
остальные — по жанру или настроению:

```
/wave kind:my        # Моя волна
/wave kind:rusrock   # русский рок
/wave kind:rusrap    # русский рэп
/wave kind:rock      # рок (pop, rap, electronic, metal, indie, jazz, classical)
/wave kind:calm      # спокойное (happy, energetic, romantic)
```

Волна работает как радио: бот сам запрашивает следующие порции треков, так что
очередь не заканчивается. Чтобы выключить — «Выключить волну» в панели или
`/stop`.

## Панель плеера

Одна панель на все функции. Появляется после `/radio` / `/play` или по команде
`/panel` (старую удаляет), **закрепляется** в канале и обновляется на месте.

Кнопки:

- ⏯ **Пауза** — пауза/продолжить (у живого радио пауза = стоп потока,
  продолжение = подключение к эфиру заново);
- ⏭ **Пропустить** — следующий трек или перезапуск радио;
- ⏹ **Стоп** — остановить и выйти из канала;
- 🧹 **Очистить** — убрать очередь;
- 🔀 **Перемешать** — случайный порядок очереди;
- 🔎 **Поиск** — открывает окно ввода, ищет в Яндекс.Музыке и показывает
  список треков на выбор;
- 🔗 **Ссылка** — открывает окно ввода, принимает ссылку на трек/альбом/плейлист;
- 📋 **Очередь** — показывает очередь (видно только тебе).

Списки:

- 📻 **Радиостанция** — Soundpark Deep, Свое FM или «Выключить радио»;
- 🔊 **Громкость** — 0–150 %;
- 🌊 **Волна** — Моя волна, русский рок, русский рэп, жанры (рок, поп, рэп,
  электроника, джаз…) и настроения (спокойное, весёлое, энергичное,
  романтичное) или «Выключить волну».

Волна — бесконечный поток: очередь пополняется сама порциями по 5 треков, пока
волна включена. Требует токен Яндекс.Музыки (как и всё остальное из Яндекса).

Панель показывает текущий трек, следующие 5 из очереди и громкость, сама
обновляется при смене трека и переживает перезапуск бота (сохраняется в
`panel.json`).

Закрепление требует права **«Управление сообщениями»** у бота. Если права нет,
панель просто не закрепится (в логе будет предупреждение).

Если нужно, чтобы панель ещё и переезжала вниз после сообщений — задай
`panel_repost_after` (например, `5`; `0` — стоит на месте). Отдельный канал для
панели: `panel_channel_id`.

`/queue` — полная очередь, `/search запрос` — поиск по Яндекс.Музыке с
выпадающим списком: выбрал трек, он сразу встал в очередь.

Ответы на команды **эфемерные** — их видит только тот, кто вызвал (в чате не
остаётся мусора). Служебные сообщения в канале музыки (например, «взял первые N»)
удаляются через 25 секунд. В чате остаётся только панель.

## Как это устроено

- FFmpeg читает поток и отдаёт PCM 48 кГц / стерео, Discord его проигрывает.
- `-reconnect` в FFmpeg + свой перезапуск через 3 с = устойчивость к обрывам.
- Бот заходит «глухим» (`self_deaf`), чтобы не тратить трафик на приём звука.
- Если Discord выкинет бота из канала, он попробует вернуться 5 раз.
- Режим 24/7 не нужен: бот сидит в канале, пока не сделаешь `/stop`.
  Premium, как у Cakey Bot, не требуется.
- Лог: `bot.log` (перезаписывается по кругу, максимум ~3 МБ).

## Если что-то не работает

| Симптом | Что делать |
|---|---|
| `Токен не задан` | Впиши токен в `config.json` или `.env` |
| `Discord не принял токен` | Сбрось токен заново в Developer Portal → Bot → Reset Token |
| `Включи MESSAGE CONTENT INTENT` | Developer Portal → Bot → Privileged Gateway Intents → Message Content Intent → Save. Бот работает и без него, но не читает чат |
| Команд нет в списке | Проверь `guild_id` в `config.json` (ID сервера), перезапусти бота, обнови Discord (Ctrl+R) |
| Бот в канале, но тишина | Проверь в `bot.log` строку `(E2EE: ...)`: должно быть `да`. Если `НЕТ` — `pip install "davey==0.1.7"` (версия 0.2.0 ломает шифрование) и перезапуск |
| Поток замолчал | `/skip` — перезапустит. Обычно бот делает это сам через 3 с |
| `Already playing audio` в логе | Бот сам повторяет запуск; если повторяется — `/stop` и `/radio` заново |
| YouTube-ссылка не играет | Новый yt-dlp требует JS-рантайм (Deno). Проще кидать прямые ссылки или mp3-вложения |
| Трек из Яндекса играет 30 секунд | Нет токена Яндекс.Музыки (или нет Плюса для этого трека). `/yandextoken` |
| В логе `E2EE: НЕТ` | DAVE-ключ не готов; бот ждёт его до 8 с. Если `НЕТ` всё время — проверь `pip show davey` (должна быть 0.1.7) |
| Бот пропал после сна ПК | Компьютер уснул. Для круглосуточной работы нужен VPS или отключённый сон |

## Файлы

```
radio-bot/
├─ bot.py              код бота
├─ yandex.py           клиент Яндекс.Музыки (треки, альбомы, плейлисты)
├─ config.json         токен и настройки (создаётся при первом запуске)
├─ config.example.json образец настроек
├─ requirements.txt    зависимости
├─ start.bat           запуск (сам ставит всё при первом старте)
├─ stop.bat            остановка бота
├─ check.bat           проверка FFmpeg и потоков
├─ bot.log             лог бота
└─ ffmpeg.log          диагностика FFmpeg (если что-то молчит — смотри здесь)
```

Папку можно перенести в любое место — главное, чтобы `ffmpeg` был в PATH или
указан в `ffmpeg_path`.
